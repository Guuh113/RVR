# RVR — Realidade Virtual

Site institucional responsivo de página única em HTML, CSS e JavaScript, pronto para hospedagem estática no Render.

## Funcionalidades
- Logo centralizada que diminui gradualmente com a rolagem.
- Experiências VR e VR + TV em cards independentes com botões Ver mais.
- Layout responsivo, sem menu hambúrguer, sem catálogo e sem painel administrativo.
- Botões Escolher em cada card abrem o WhatsApp (12) 99129-6081, com mensagem específica para VR ou VR + TV. A mensagem é preenchida; o cliente confirma o envio no WhatsApp.
- Imagem externa do Meta Quest 2 de Wikimedia Commons; atribuição: Maximilian Prandstätter, "Oculus Quest II (50844634326).jpg", CC BY 2.0: https://commons.wikimedia.org/wiki/File:Oculus_Quest_II_(50844634326).jpg

## Render
Tipo: Static Site; build command: `echo ready`; publish directory: `.`.

Para abrir localmente, abra `index.html` ou execute `python -m http.server 8000` nesta pasta.
