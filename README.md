# RVR — Realidade Virtual

Site minimalista responsivo, com cards VR e VR + TV, botões de orçamento pelo WhatsApp e avaliações claramente ilustrativas.

Logo fornecida pelo cliente. Imagem ilustrativa dos óculos gerada para o projeto. Os recursos visuais estão incorporados ao CSS para evitar dependências externas.

As avaliações do Google ainda não estão conectadas.
